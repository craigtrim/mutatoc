# Third-party components

The C library vendors cJSON 1.7.19 under the MIT license. Its license is in `vendor/cjson/LICENSE`; upstream locations and checksums are in `vendor/manifest.json`. Local patches preserve large integer JSON values and embedded NUL characters, reject malformed string escapes/control characters, and make parser error state thread-local. Embedded NUL uses modified UTF-8 inside the implementation and standard `\u0000` escaping on JSON boundaries; invalid UTF-8 is rejected at input boundaries.

Upstream Mutato tests and ontology fixtures are retained under Mutato's MIT license, copied in `LICENSE`. The reference source revision and test manifests identify their origin.

The workers import separately installed spaCy, RDFLib, and their dependencies. Their distributions retain their own licenses. The trained model is installed from the original reference archive and retains its distribution license. These packages and model weights are not vendored in the source repository; the Windows packaging script includes their installed distributions and license metadata. Runtime and test dependency pins are recorded separately.

The RDF 1.1 Turtle suite under `tests/w3c-turtle` comes from the W3C RDF test repository. Its license notice, source locations, and resource hashes are retained there. Graph comparison treats RDF 1.1 plain literals as `xsd:string` and compares blank nodes by graph isomorphism.

Unicode tables are generated by `scripts/generate_unicode.py` using Python 3.11 Unicode 14 behavior. The packaged Python interpreter retains its PSF license in `runtime/python/LICENSE.txt`. URI resolution follows RFC 3986, with normal and abnormal reference-resolution examples included in the text tests.


LingPatLab 1.1.1 at revision `2ed920f1bc7e57d8c74b5b35a54e90f2b7f8ed71` is ported into the C library under its MIT license, retained in `vendor/lingpatlab/LICENSE`. Its 17 original tests and support data are retained with provenance under `tests/lingpatlab/upstream`. No LingPatLab Python implementation is loaded by the production runtime.

The compiled WordNet membership table contains the 88,013 hashes distributed by wordnet-lookup 1.3.4. Its license is retained in `vendor/wordnet-lookup/LICENSE`. C implements its MD5 membership keys, Python 3.11 lowercase/strip behavior, NFKD-to-ASCII fallback and plural fallback. MD5 serves dictionary lookup and is not used for security. Unicode punctuation follows the reference's unicodedata2 18.0.0 categories; other character operations follow Python 3.11 Unicode 14.0. Generated table checksums are in `vendor/lingpatlab/data-manifest.json`.

Unicode, unicodedata2 and Python license notices are retained in `vendor/unicode/`. The unicodedata2 package is used only to generate checked-in punctuation tables, not by the runtime.
